Public pages

Ten public MIT Sloan EMBA pages, saved as small text files. Open to everyone. Use them if you do not have the class code, or if the class pack will not open.

They are the public pages for prospective students, fetched on September 18, 2026. Each file starts with its source address. They describe the program in general; they do not contain the bio book or the orientation agenda, which are in the class pack. Your own materials are better still. Together the ten files are about 14,600 tokens (14,586, counted as one message).

Download the public pages (zip, 10 files)

Unzip it, then add the files to your Project's Context. Each file is also linked below.
